## 何を比べたか

移動様態判定(方式C・E)に使うヨーレートを、ジャイロの重力方向への投影から、yaw_deg の変化率
(約0.1秒離れた行との差を時間で割る)に変えた。0805の3件の acc_* は重力を含まない線形加速度で、
従来の投影はヨーレートになっていなかった(1441・1442でyaw_degの変化率との相関 −0.02・0.04)。

## 読み方

- 修正後も曲がり判定は82〜100%で、「曲がりが終わらない」状態は解消していない。正しいヨーレートでも
  直進中の75パーセンタイルは歩行の揺れで15〜19度/秒あり、終了しきい値10度/秒を下回らないため。
  これは終了しきい値を校正用データ(calib)で決め直すことで扱う(この修正の範囲外)。
- 様態が変わった歩(方式E・seed=42のログ): 修正前は3本とも序盤(3・2・8歩目)に曲がりに入り、1441・1442は
  終わり近く(66・74歩目)に一度だけ直進へ戻る。修正後は1438が17・43歩目で直進へ戻って32・45歩目で再び
  曲がりに入り、1441は1歩目で曲がりに入って最後まで戻らず(100%)、1442は73歩目に戻る。
- 終点までの距離の差は最大0.4 m、全滅回数の差は1438のEで+0.83回、1441のEで−2.17回。曲がりがほぼ常に
  続く状態は前後で同じなので、今の段階で方式の優劣を論じる材料にはならない。
